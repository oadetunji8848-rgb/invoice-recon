# Your data goes here

- `invoices/` – your PDF invoices (any number, any file names)
- `bank_ledger.csv` – your bank export for the same period

Uploading either one starts the **Reconcile invoices** workflow. Results appear on the run's page under *Actions*.

> ⚠️ Anything in this folder is visible to whoever can see the repository. Keep the repository **private** if these are real invoices or bank statements.
